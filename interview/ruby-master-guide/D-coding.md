### D-0001 — Apple Stocks

**Difficulty:** Intermediate · **Topic:** Additional technical topics · **Source occurrences:** 1

**Interview question**

Apple Stocks

**Direct answer**

Scan prices once, tracking the minimum earlier price and the best sale profit seen so far.

**Detailed explanation**

Compute a candidate sale before updating the minimum so buying and selling at the same timestamp is not used. O(n) time and O(1) extra numeric state. If one trade is mandatory, a falling series yields a negative result; if no trade is allowed, clamp the answer to zero as a separate policy.

**Practical example**

```ruby
# 37. One buy before one sell is required, even if every return is negative.
def maximum_stock_profit(prices)
  raise ArgumentError, 'at least two prices required' if prices.length < 2
  minimum, best = prices[0], prices[1] - prices[0]
  prices.each_with_index do |price, index|
    next if index.zero?
    best = [best, price - minimum].max
    minimum = [minimum, price].min
  end
  best
end

# Example usage:
p maximum_stock_profit([10, 7, 5, 8, 11, 9]) # 6
```

### D-0002 — Bracket Validator

**Difficulty:** Advanced · **Topic:** Additional technical topics · **Source occurrences:** 1

**Interview question**

Bracket Validator

**Direct answer**

Use a stack of opening brackets and require each closing bracket to match the latest opener.

**Detailed explanation**

Push (, [ and {. For a closer, fail if the stack is empty or its top is not the matching opener. Accept only if the stack is empty at the end. O(n) time and O(n) worst-case stack space. The code ignores non-bracket characters by explicit policy.

**Practical example**

```ruby
# 23. Ignore non-bracket characters; match (), [] and {}.
def valid_brackets?(string)
  closing = { ')' => '(', ']' => '[', '}' => '{' }
  stack = []
  string.each_char do |char|
    if closing.value?(char)
      stack << char
    elsif closing.key?(char)
      return false unless stack.pop == closing[char]
    end
  end
  stack.empty?
end

# Example usage:
p valid_brackets?("{a:[()]}") # true
p valid_brackets?("([)]") # false
```

**Important points and follow-ups**

- A counter alone cannot check mixed bracket nesting.

### D-0003 — Cafe Order Checker

**Difficulty:** Advanced · **Topic:** Additional technical topics · **Source occurrences:** 1

**Interview question**

Cafe Order Checker

**Direct answer**

Walk the served sequence while advancing the head pointer of whichever source queue matches each order.

**Detailed explanation**

With globally unique order IDs, each served order must match the next unserved takeout or dine-in order. Reject length mismatches and leftovers. O(n) time and O(1) auxiliary state. If IDs can repeat across streams, the greedy choice can become ambiguous and needs stronger identity or a different algorithm.

**Practical example**

```ruby
# 30. Orders have distinct IDs, are partitioned into two given streams.
def first_come_first_served?(takeout, dinein, served)
  return false unless served.length == takeout.length + dinein.length
  i = j = 0
  served.each do |order|
    if i < takeout.length && order == takeout[i]
      i += 1
    elsif j < dinein.length && order == dinein[j]
      j += 1
    else
      return false
    end
  end
  i == takeout.length && j == dinein.length
end

# Example usage:
p first_come_first_served?([1, 3], [2, 4], [1, 2, 3, 4]) # true
```

### D-0007 — Find in Ordered Set

**Difficulty:** Intermediate · **Topic:** Additional technical topics · **Source occurrences:** 1

**Interview question**

Find in Ordered Set

**Direct answer**

Use binary search on a sorted array, halving the candidate interval each step.

**Detailed explanation**

Compare the midpoint with the target, discard the impossible half and stop when found or the interval is empty. O(log n) comparisons and O(1) space assume random indexed access and a sorted collection under the same comparison rule.

**Practical example**

```ruby
# 11. Sorted ascending comparable values.
def binary_include?(array, target)
  low, high = 0, array.length - 1
  while low <= high
    mid = (low + high) / 2
    return true if array[mid] == target
    array[mid] < target ? low = mid + 1 : high = mid - 1
  end
  false
end

# Example usage:
p binary_include?([1, 3, 5, 7], 5) # true
```

### D-0008 — Find Repeat, Space Edition

**Difficulty:** Advanced · **Topic:** Additional technical topics · **Source occurrences:** 1

**Interview question**

Find Repeat, Space Edition

**Direct answer**

Under the bounded-domain variant, binary-search the value range and count how many values fall in each half.

**Detailed explanation**

For n+1 values in 1..n, the pigeonhole principle guarantees a duplicate. If at most mid values can fit in the lower range but more than mid appear there, that range contains a duplicate. O(n log n) time and O(1) extra state, without modifying the input.

**Practical example**

```ruby
# 34. n+1 values in 1..n with at least one duplicate; no mutation, O(n log n).
def duplicate_low_space(numbers)
  low, high = 1, numbers.length - 1
  while low < high
    mid = (low + high) / 2
    count = numbers.count { |number| number <= mid }
    count > mid ? high = mid : low = mid + 1
  end
  low
end

# Example usage:
p duplicate_low_space([1, 3, 4, 2, 2]) # 2
```

### D-0009 — Find Repeat, Space Edition BEAST MODE

**Difficulty:** Advanced · **Topic:** Additional technical topics · **Source occurrences:** 1

**Interview question**

Find Repeat, Space Edition BEAST MODE

**Direct answer**

Interpret the bounded-domain array as pointers and use Floyd’s cycle detection to find the duplicate entry value.

**Detailed explanation**

For n+1 elements containing values in 1..n, following indices eventually enters a cycle. One phase finds a meeting point; restarting one pointer at the path’s beginning and moving both one step finds the cycle entrance. O(n) time, O(1) space and no mutation under the stated standard assumptions.

**Practical example**

```ruby
# 35. Same bounded-domain assumptions; Floyd's cycle algorithm, O(n), O(1).
def duplicate_floyd(numbers)
  slow = fast = numbers[0]
  loop do
    slow = numbers[slow]
    fast = numbers[numbers[fast]]
    break if slow == fast
  end
  slow = numbers[0]
  until slow == fast
    slow, fast = numbers[slow], numbers[fast]
  end
  slow
end

# Example usage:
p duplicate_floyd([1, 3, 4, 2, 2]) # 2
```

**Important points and follow-ups**

- This is not a solution to an arbitrary unconstrained array duplicate problem.

**Difficulty:** Advanced · **Topic:** Additional technical topics · **Source occurrences:** 1

**Interview question**

Find Rotation Point

**Direct answer**

Binary-search for the smallest element by comparing a midpoint with the right endpoint.

**Detailed explanation**

**Practical example**

```ruby
# 12. Rotated sorted distinct values: O(log n). Duplicates may force O(n).
def rotation_index(array)
  return nil if array.empty?

    mid = (low + high) / 2
    if array[mid] > array[high]

    elsif array[mid] < array[high]
      high = mid
    else
      high -= 1
    end
```

### D-0012 — Highest Product of 3

**Difficulty:** Advanced · **Topic:** Additional technical topics · **Source occurrences:** 1

**Interview question**

Highest Product of 3

**Direct answer**

Track the three largest numbers and the two smallest numbers, then compare the relevant products.

**Detailed explanation**

The maximum is either the product of the three largest or the largest times the two most negative. Maintaining fixed-size candidate arrays keeps O(n) time and O(1) extra space; sorting the entire input would cost O(n log n). Require at least three numbers.

**Practical example**

```ruby
# 39. Track three largest and two smallest values; negatives can win.
def highest_product_three(numbers)

end
```

Walk to the rightmost node; the second largest is its parent unless that node has a left subtree, whose largest value is the answer.

### D-0055 — Implement A Queue With Two Stacks

**Difficulty:** Intermediate · **Topic:** Background work and real-time features · **Source occurrences:** 1

**Interview question**

**Direct answer**

Use an incoming stack for pushes and an outgoing stack for removals, transferring only when outgoing is empty.

**Detailed explanation**

Each element moves between the stacks at most once before removal. Individual transfers can take O(n), but each queue operation is amortized O(1). An empty dequeue should have an explicitly defined result or exception.

**Practical example**

```ruby
# 4. Amortized O(1) enqueue/dequeue; a transfer can take O(n).
class TwoStackQueue
  def initialize
    @incoming, @outgoing = [], []
  end
  def push(value)
    @incoming.push(value)
    self
  end
  def shift
    if @outgoing.empty?
      @outgoing << @incoming.pop until @incoming.empty?
    end
    raise IndexError, 'empty queue' if @outgoing.empty?
    @outgoing.pop
  end
end
```
